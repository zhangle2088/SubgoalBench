# SubgoalBench Skills

These short guides are the operational entry point for the released artifact. They are intentionally smaller than the project development notes.

- [Add a model](add_model.md): register a provider or OpenAI-compatible endpoint.
- [Run the benchmark](run_benchmark.md): run a smoke test, a suite, or the full benchmark.
- [Measure coordinates](measure_coordinates.md): measure execution friction ($\Phi_t$) and bridging strength ($\Delta_t$).

All commands assume the repository root, `uv sync --dev`, and credentials supplied through environment variables. Never commit API keys.
