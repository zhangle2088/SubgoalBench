# Provenance and New Value

## Component provenance

| Component | Provenance | SubgoalBench contribution |
| --- | --- | --- |
| Agent pipeline and simulated tools | Adapted from the AgentDojo execution framework | Provides trusted tool execution, state transitions, and validator interfaces |
| Base workflow scenarios | Adapted from AgentDojo and AgentDyn environments where documented | Supplies realistic multi-step workflow states and carrier locations |
| Target payloads | Authored and normalized for this benchmark | Provides an action-matched spectrum of unauthorized target actions |
| Contextual prefixes | Newly authored eight-level gradients per payload | Controls how strongly a payload is bridged to the active workflow |
| Coordinate probes | Newly authored rubrics and estimators | Measures execution friction and bridging strength on a shared scale |
| Controls and analysis | Newly authored matched conditions and aggregation | Separates template effects, bridge effects, and model-specific boundaries |

The benchmark is therefore not a relabeling or repackaging of an existing suite. Its scientific contribution is the fixed-state, action-matched, prefix-graded design and the joint measurement of execution friction and bridging strength. The release retains upstream notices and records inherited files and modifications in the artifact manifest.
